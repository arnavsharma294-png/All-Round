# All Round

Interface prototype for SVG03, the Know Thyself challenge. The browser demo shows a personal journal covering sleep, movement and habits. The website uses sample records.

Open `dist/index.html` in a browser. The file is self-contained and can be opened offline. Scroll through the experience to see the WebGL sculpture transform and the privacy orbit turn. The motion follows your device’s reduced motion preference. The journal includes metric switching, daily readings, a sample insight and a locally saved habit nudge.

To rebuild the HTML after a source edit, run `node build.mjs`. There are no install steps or runtime services.
